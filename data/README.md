# Portal Gun Research Data

Esta pasta contém a camada estruturada de conhecimento do Portal Gun.

## Tipos

- `concepts`: conceitos e conhecimentos de referência.
- `hypotheses`: hipóteses que ainda precisam de teste ou revisão.
- `questions`: perguntas abertas.
- `experiments`: protocolos e investigações.
- `projects`: projetos relacionados.

## Regra epistemológica

Cada registro deve deixar claro se é **fato/conhecimento de referência**, **hipótese**, **observação**, **pergunta** ou **especulação**. Uma experiência pessoal pode gerar uma observação útil, mas não deve ser tratada automaticamente como evidência causal.

## Objetivo

O banco deve evoluir para uma rede em que conceitos, hipóteses, perguntas, experimentos, fontes e resultados possam ser relacionados por IDs.
